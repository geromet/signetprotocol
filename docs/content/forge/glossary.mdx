# Glossary

| Term | Meaning |
|---|---|
| **Appearance palette** | The items of a game that can stand for archetypes |
| **Archetype** | Something that exists in the world, described by its function, without graphics |
| **Calibration** | Setting up controls and measuring before playing |
| **Capabilities** | What a game declares it can send and show |
| **Deterministic** | Always giving the same result for the same situation |
| **Intent** | What the player wants to do |
| **Motion profile** | Measurements of how a game moves: speed, jump, turn |
| **Resolver** | Whatever picks the best option from a list: a table, a person or a model |
| **Signet Forge** | Companion tool to create, review and improve translations |
| **Standard translator** | The SDK component that converts between a game and the shared meaning |
| **Translation profile** | File with a translator's pinned decisions |
