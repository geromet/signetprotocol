# Signet Protocol — notes for agents working on this repository

Signet Protocol (formerly "Multiverso") is an open protocol and SDK that lets players with
**different games** join the same world: a neutral, authoritative server owns geometry, rules and
bodies; each player sees and controls it with their own game through a **translator**. The user
owns the "Signet Protocol" name. **Talk to the user in Spanish.**

## Layout

| Path | What |
|---|---|
| `crates/signet-sdk` | Rust core: `protocolo` (Signet/1 wire types), `reglas` (game modes, `TIC` = 1/20 s), `prediccion` (numbered commands + reconciliation), `cliente` (engine-agnostic client), `mundo` (native worlds, `.mvm` format, `ConstructorMapa`), `traductor` (translator traits + `Manifiesto`), `conformidad` (codes T01–T07, R01–R02, M01–M04) |
| `crates/signet-sdk/mundos/*.mvm` | Native worlds bundled in the SDK (`signet:nexo`), generated by `examples/crear_nexo.rs` |
| `crates/signet-ffi` | C ABI: `include/signet.h`, `sg_*` functions, builds `signet.dll/.so/.dylib` |
| `bindings/csharp/Signet.cs` | C# P/Invoke binding (preview, untested in Unity) |
| `bindings/typescript` | `@signet/sdk` for Node: wire types + client, no prediction |
| `servidor/` | Dedicated server (Docker). Uses the SDK's `protocolo`, `reglas`, `mundo` through re-export shims; own importers `doom.rs` (WAD) and `quake3.rs` + `openarena.rs` (IBSP v46 from `.pk3`) |
| `docs/` | Next.js 15 + Nextra 4.6 documentation (English), static export to `out/`, Pagefind search |

## Commands

```bash
cargo test --release --workspace                      # 16 tests must pass
cargo run --release --example crear_nexo              # regenerate mundos/nexo.mvm (checks conformance)
cargo run --release --example conformidad -- --servidor <host>
docker build -f servidor/Dockerfile -t signet-server .
docker run -d --name signet --restart unless-stopped -p 7777:7777 -e SIGNET_WORLD=signet:nexo signet-server
cd docs && npm install && npm run build               # needs the zod 4.1.12 npm override (already in package.json)
```

`SIGNET_WORLD`: `signet:nexo` (native), `doom:E1M1` (default), `openarena:<map>`.

## Rules that matter

- **Signet/1 is append-only:** new fields must be optional with a serde default; never rename or
  remove fields. The wire vocabulary is intentionally **Spanish** (`Intencion`, `avance`, `techo`…)
  for compatibility; an English vocabulary is planned as Signet/2. Public docs, C/C#/TS APIs, logs
  and messages are English.
- **Determinism:** client prediction and server must run the same `reglas::doom::mover` (sub-steps
  ≤ 0.1 m) with one numbered command per tick. Do not change movement on one side only.
- **Native world prefix** is `signet:`; the legacy `multiverso:` must keep working
  (`mundo::mapa_nativo`, server `main.rs`). Env `MULTIVERSO_MUNDO` is still accepted.
- **Legal:** never commit game files (WADs, `.pk3`, textures, sounds, Mojang assets) or links to
  unofficial copies. Translators read the player's own installation. No injection into online
  games. The Docker image downloads only redistributable data (Doom 1.9 shareware, OpenArena 0.8.8
  GPL) with checksum verification.
- Docs screenshots in `docs/public/img/demos` come from the reference client on the Windows PC.

## State (beta 0.1, 2026-10-03)

Working end to end: Doom/OpenArena/Minecraft/Signet clients in one match against the Mac server,
0 prediction corrections, native world Nexo. Known gaps: no jumping in `doom:deathmatch` (Quake pits
trap players), 2.5D terrain, OpenArena shader textures render white, Minecraft gateway still sends
unnumbered intents, C# untested. Not published yet (no GitHub org chosen, docs not deployed).
