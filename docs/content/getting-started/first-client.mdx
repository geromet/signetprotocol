# Your first client

A client does four things every frame:

1. **Set the intent** of the player: forward, strafe, look direction, run, fire, weapon.
2. **Advance** by the elapsed time. The SDK predicts, sends the commands and tells you where to draw.
3. **Read** the other bodies and the events to draw them with your game.
4. **Draw**: the camera goes at the returned position plus eye height (1.3 m).

    ```rust filename="main.rs"
    use signet_sdk::{cliente::Cliente, protocolo::Intencion};

    fn main() {
        let mut c = Cliente::conectar("192.168.1.212", "my-game");   // connect
        let mut yaw = 0.0;
        loop {
            let dt = 1.0 / 60.0;
            if let Some(y) = c.tomar_yaw_aparicion() { yaw = y; }   // on (re)spawn
            // avance = forward
            c.fijar_intencion(Intencion { avance: 1.0, yaw, ..c.intencion() });
            if let Some([x, y, z]) = c.avanzar(dt) {                 // advance
                // place_camera(x, y + 1.3, z, yaw);
            }
            for j in c.jugadores() { /* draw player j with your models */ }
            for e in c.tomar_eventos() { /* sounds, effects, HUD */ }
            std::thread::sleep(std::time::Duration::from_millis(16));
        }
    }
    ```

  <Tabs.Tab>
    ```csharp filename="SignetPlayer.cs"
    using Signet;
    using UnityEngine;

    public class SignetPlayer : MonoBehaviour {
        Client c;
        float yaw;
        void Start() => c = new Client("192.168.1.212", "unity");
        void Update() {
            if (c.SpawnYaw(out var y0)) yaw = y0;
            yaw -= Input.GetAxis("Mouse X") * 0.05f;
            c.Intent(Input.GetAxis("Vertical"), Input.GetAxis("Horizontal"), yaw,
                     Input.GetKey(KeyCode.LeftShift), Input.GetMouseButton(0), Weapon.Pistol);
            // Signet uses -z as north: flip z for Unity's coordinate system.
            if (c.Advance(Time.deltaTime, out var x, out var y, out var z))
                transform.SetPositionAndRotation(new Vector3(x, y + 1.3f, -z),
                    Quaternion.Euler(0, -yaw * Mathf.Rad2Deg, 0));
        }
        void OnDestroy() => c?.Dispose();
    }
    ```

    ```ts filename="bot.ts"
    let yaw = 0;
    setInterval(() => {
      yaw += 0.05;
      c.intent({ forward: 1, yaw });
    ```

<Callout type="warning">
**Axis conventions.** In Signet/1 north is −z and positive `yaw` turns left (like Bevy and most right-handed, y-up engines). In a left-handed engine such as Unity, flip `z` and the sign of `yaw` when drawing, as in the C# example.
</Callout>
